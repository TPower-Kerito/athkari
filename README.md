# تطبيق أذكاري (Athkari PWA) 🌿

تطبيق ويب تقدمي (Progressive Web App - PWA) مخصص للهواتف الذكية وأجهزة الكمبيوتر، يعمل بالكامل **بدون إنترنت (Offline 100%)**، ومصمم خصيصاً للاستخدام الشخصي اليومي لقراءة أذكار الصباح والمساء والتسبيح.

---

## 🌟 مميزات التطبيق

1. **أذكار الصباح والمساء كاملة**:
   - نصوص شرعية موثقة ومشكلة بالكامل بتشكيل واضح ودقيق.
   - ذكر فضل كل ذكر ومصدره الشرعي.
   - عداد تفاعلي لكل ذكر ينقص عند اللمس مع توضيح العدد المتبقي.
   - اهتزاز تفاعلي خفيف (Haptic Feedback) وصوت ناعم عند الضغط وعند إتمام الذكر.
   - تمرير تلقائي لطيف للذكر التالي فور إتمام الذكر الحالي.

2. **السبحة الإلكترونية (Digital Tasbeeh)**:
   - مساحة لمس دائرية ضخمة ومريحة لإبهام اليد.
   - صيغ تسبيح جاهزة (سبحان الله، الحمد لله، الله أكبر، لا إله إلا الله، أستغفر الله...).
   - عداد دورات ومؤشر حلقة مرئي لإتمام الدورات (33 أو 100).
   - إحصاء إجمالي التسبيحات اليومية.

3. **حفظ التقدم وسلسلة الأيام (Streak & Statistics)**:
   - يحفظ أين توقفت تلقائياً على هاتفك (Local Storage) حتى لو أغلقت التطبيق.
   - عداد الأيام المتتالية (Streak 🔥) لتشجيعك على المداومة اليومية.
   - إحصائيات بعدد مرات إتمام أذكار الصباح والمساء وإجمالي التسبيحات وسجل لآخر 7 أيام.
   - يتجدد التقدم تلقائياً مع بداية كل يوم جديد مع الحفاظ على سجل إنجازاتك.

4. **تخصيص المظهر والقراءة**:
   - **الوضع الليلي (Dark Mode)** المريح للعينين في الصباح الباكر والمساء + وضع نهاري نقي.
   - **التحكم في حجم الخط (A+ / A-)** لتكبير وتصغير خط الأذكار لراحة القراءة.
   - إمكانية كتم الصوت أو إلغاء الاهتزاز حسب الرغبة.

5. **يعمل بدون إنترنت وتثبيت كأي تطبيق أصلي**:
   - مزود بـ Service Worker و Web App Manifest وأيقونات عالية الدقة.
   - يثبت مباشرة على شاشة الهاتف كأيقونة تطبيق ويعمل في وضع ملء الشاشة (Standalone) بدون شريط المتصفح.

## 🚀 كيفية تشغيل التطبيق وتثبيته على هاتفك

### الطريقة الأولى: التشغيل عبر الشبكة المحلية (Wi-Fi)

1. تأكد أن هاتفك وجهاز الكمبيوتر متصلان بنفس شبكة الواي فاي (Wi-Fi).
2. على جهاز الكمبيوتر، افتح المجلد:
   ```text
   F:\Anti
   ```
3. اضغط مرتين على الملف:
   ```text
   run_app.bat
   ```
4. ستظهر لك شاشة سوداء تخبرك برابط الهاتف، مثل:
   ```text
   http://192.168.1.X:8080
   ```
5. افتح هذا الرابط في متصفح **Google Chrome** على هاتفك الأندرويد.
6. اضغط على النقاط الثلاث أعلى يسار/يمين المتصفح واختر:
   - **"تثبيت التطبيق" (Install app)** أو **"إضافة إلى الشاشة الرئيسية" (Add to Home screen)**.
7. سيظهر تطبيق **"أذكاري"** بأيقونته الجميلة على شاشة هاتفك، ويمكنك فتحه واستخدامه بدون إنترنت في أي وقت!

---

### الطريقة الثانية: رفعه على الإنترنت مجاناً في دقيقة واحدة (الأفضل للاستخدام الدائم)

لكي يظل التطبيق معك دائماً وتفتحه من أي مكان أو على أي هاتف جديد بدون الحاجة لتشغيل الكمبيوتر:

1. **عبر Netlify Drop (أسهل طريقة بدون كتابة أوامر)**:
   - افتح موقع [app.netlify.com/drop](https://app.netlify.com/drop).
   - اسحب مجلد `F:\Anti` وأفلته في الصفحة.
   - سيعطيك رابطاً سريعاً ومجانياً وآمناً (HTTPS) مثل `https://athkari-xyz.netlify.app`.
   - افتح هذا الرابط على هاتفك واضغط "تثبيت التطبيق".

2. **عبر GitHub Pages**:
   - ارفع ملفات المجلد إلى مستودع (Repository) في GitHub.
   - فعل خيار GitHub Pages من إعدادات المستودع (Settings -> Pages).
   - ستحصل على رابط دائم ومجاني مدى الحياة.

## 📁 هيكلية ملفات المشروع

```text
f:\Anti\
├── index.html         # الواجهة الرئيسية والهيكل
├── style.css          # التصميم، الألوان، الخطوط، والوضع الليلي
├── app.js             # منطق التطبيق، العدادات، الصوت، الاهتزاز، والتخزين
├── athkar.js          # بيانات الأذكار والتشكيل والأعداد والفضائل
├── manifest.json      # ملف تعريف التطبيق للأندرويد (PWA Manifest)
├── sw.js              # Service Worker للتشغيل بدون إنترنت
├── server.py          # خادم محلي خفيف بلغة بايثون مع كشف الـ IP
├── run_app.bat        # ملف تشغيل بضغطة زر واحدة على ويندوز
├── generate_icons.py  # كود توليد أيقونات التطبيق
├── icons/             # أيقونات التطبيق بمختلف المقاسات
└── README.md          # دليل الاستخدام والتثبيت
```

تقبل الله منا ومنكم صالح الأعمال وجعله في ميزان حسناتكم! 🌿
